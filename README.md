# Dice Throw Game

A simple browser-based two-player dice game built with plain HTML, CSS, and JavaScript.

## Files in this repository

- `/home/runner/work/Dice-throw-Game/Dice-throw-Game/index.html` – page structure and game UI
- `/home/runner/work/Dice-throw-Game/Dice-throw-Game/index.css` – game styling and responsive layout
- `/home/runner/work/Dice-throw-Game/Dice-throw-Game/index.js` – game logic, scoring, and round handling

## How to run

1. Open `/home/runner/work/Dice-throw-Game/Dice-throw-Game/index.html` in any modern browser.
2. Enter the number of rounds.
3. Click **Start** and continue with **next round** until the game ends.

## Gameplay summary

- Both players roll a die each round.
- The player with the higher value wins the round.
- Round winners add both dice values to their total scores.
- Draws are tracked and can affect remaining rounds according to the game script.
